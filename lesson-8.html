概念 · 01

函数 —— 工具箱

把一段能重复用的代码包起来起个名。

💡比喻：函数像工具箱：把常用工具装进去，随取随用。
示例代码 · 点 ▶ Run 试运行
demo.py
def add(a, b):
    return a + b

result = add(3, 5)
print(result)   # 8

def greet(name):
    print("你好,", name)

greet("小明")
▶ Run
💡 关键点：def 函数名(参数): 函数体缩进；return 返回结果，没有 return 返回 None。
概念 · 02

参数与返回值

参数是输入，返回值是算出的结果。

💡比喻：参数是投进去的材料，return 是交回来的成品。
示例代码 · 点 ▶ Run 试运行
demo.py
def avg(nums):
    return sum(nums) / len(nums)

print(avg([1, 2, 3, 4]))   # 2.5

def divide_round(a, b):
    if b == 0:
        return "除数不能为0"
    return round(a / b, 2)  # 保留两位小数

print(divide_round(10, 3))  # 3.33
▶ Run
💡 关键点：round(x,2) 四舍五入保留两位；函数里先用 if 处理边界。
概念 · 03

小海龟 · 基本命令

turtle 像一支能拐弯的画笔。

💡比喻：小海龟是画笔：前进、后退、转向、抬笔落笔。
示例代码 · 点 ▶ Run 试运行
demo.py
import turtle as t

t.forward(100)    # 前进
t.left(90)       # 左转90度
t.pensize(5)      # 画笔粗细
t.pencolor("red") # 画笔颜色
t.penup()         # 抬笔（不画线）
t.pendown()       # 落笔
t.hideturtle()    # 隐藏小海龟
t.done()          # 保持窗口
▶ Run
💡 关键点：常用命令：forward/backward、left/right、penup/pendown、pencolor/pensize、circle。end 别忘了 t.done()。
概念 · 04

画正多边形

正 n 边形：外角 = 360 / n。

💡比喻：每次前进后转 360/n 度，走 n 次就回到原点。
示例代码 · 点 ▶ Run 试运行
demo.py
import turtle as t

def draw_polygon(n, length, color):
    t.pencolor(color)
    angle = 360 / n
    for _ in range(n):
        t.forward(length)
        t.left(angle)

draw_polygon(3, 80, "red")    # 正三角形
draw_polygon(4, 100, "blue")  # 正方形
draw_polygon(6, 60, "green")  # 正六边形
t.done()
▶ Run
💡 关键点：关键：每次前进后转 360/n 度。n、length、color 参数让函数能画任意正多边形。
概念 · 05

颜色填充

begin_fill 开始，end_fill 填充。

💡比喻：先告诉海龟『我要上色』，画完再『上色』。
示例代码 · 点 ▶ Run 试运行
demo.py
import turtle as t

t.begin_fill()
t.fillcolor("red")
for _ in range(4):
    t.forward(100)
    t.left(90)
t.end_fill()
t.done()
▶ Run
💡 关键点：begin_fill() 开始记录，画完封闭图形后 end_fill() 填充。
