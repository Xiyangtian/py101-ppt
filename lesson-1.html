概念 · 01

Python 是什么？

Python 是一门编程语言，是计算机能读懂的语言。

💡比喻：Python 像一门『普通话』，你写一行，电脑就照着做一行。
示例代码 · 点 ▶ Run 试运行
demo.py
# 输出一句话到屏幕
print("Hello World")

# 也可以输出算好的结果
print(1 + 2)
▶ Run
💡 关键点：print() 就是把内容显示到屏幕的指令。Python 是解释型：一句一句边解释边执行。
概念 · 02

print —— 电脑的大喇叭

print() 把括号里的内容打印到屏幕上。

💡比喻：print = 电脑拿大喇叭喊话，喊的内容要加引号告诉电脑『这是文字』。
示例代码 · 点 ▶ Run 试运行
demo.py
# 第一个程序
print("Hello World")
print(1 + 2)
▶ Run
💡 关键点：print 里放字符串要加引号；放数字直接写。中文输出也不难。
概念 · 03

input —— 电脑的耳朵

input() 接收键盘输入；得到的一定是字符串。

💡比喻：input 是耳朵，print 是嘴巴。电脑等你说完再回应。
示例代码 · 点 ▶ Run 试运行
demo.py
name = input("请输入你的名字: ")
print("你好, " + name)

a = int(input("请输入一个整数: "))
print("你输入的数是", a)
▶ Run
💡 关键点：input() 返回字符串，要当数字算得先用 int()/float() 转。
概念 · 04

IPO —— 程序的骨架

I 输入 → P 处理 → O 输出。

💡比喻：写程序先想三件事：要什么输入、怎么处理、要什么输出。
程序流程
I nput (输入)   ──►   P rocessing (加工)   ──►   O utput (输出)
   input()                运算 / 判断 / 循环             print()
概念 · 05

变量 & 冯·诺依曼

变量是装数据的容器；了解电脑的经典结构。

💡比喻：变量 = 贴上名字标签的碗；电脑 = 输入→存储→运算→控制→输出。
结构
  • 冯·诺依曼体系结构 存储程序 + 五大部件
  • ├── 输入设备 键盘鼠标
  • ├── 存储器 存程序和数据
  • ├── 运算器 做运算
  • ├── 控制器 指挥
  • └── 输出设备 显示器
