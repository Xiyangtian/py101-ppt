概念 · 01

创建列表与访问

用 [] 装一组数据，元素用逗号隔开。

💡比喻：列表像一排带编号的储物格，编号从 0 开始数。
示例代码 · 点 ▶ Run 试运行
demo.py
numbers = [1, 1, 3, 4, 7, 11]
animals = ["dog", "pig", "cat", "bird"]
print(len(numbers))   # 6（长度）
print(numbers[0])     # 1（第一个，索引从 0 起）
print(numbers[-1])    # 11（最后一个，负索引 -1 起）
▶ Run
💡 关键点：正索引从 0 起，负索引从 -1 起；len() 返回元素个数。
概念 · 02

增删改

列表是可变的，能直接增、删、改。

💡比喻：append 往后塞、insert 插队、pop 拿走并告诉你拿了啥。
示例代码 · 点 ▶ Run 试运行
demo.py
animals = ["dog", "pig", "cat", "bird"]
animals[0] = "mouse"     # 改第一个
animals.append("duck")    # 末尾追加
animals.insert(1, "cow")  # 在索引1处插入
del animals[2]            # 删除索引2
popped = animals.pop()    # 删最后一个并返回
print(animals)
print(popped)
▶ Run
💡 关键点：del 不返回值；pop() 返回被删除的元素（默认删最后一个）。
概念 · 03

切片

取一段：list[start:end:step]。

💡比喻：切蛋糕：从 start 切到 end 前面一块（左闭右开）。
示例代码 · 点 ▶ Run 试运行
demo.py
lst = [1, 2, 3, 4, 5, 6]
print(lst[2:5])     # [3,4,5]（含2不含5）
print(lst[:4])      # [1,2,3,4]
print(lst[3:])      # [4,5,6]
print(lst[::-1])    # 反转
print(lst[::2])     # 步长2：隔一个取
▶ Run
💡 关键点：左闭右开：冒号左边含、右边不含。这是最容易错的地方。
概念 · 04

常用函数与方法

统计、排序、查找一网打尽。

💡比喻：len/max/min/sum 一键统计；count 数个数；sort 排序。
示例代码 · 点 ▶ Run 试运行
demo.py
nums = [2, 5, 6, 7, 8, 9, 2, 9, 9]
print(max(nums))        # 9
print(min(nums))        # 2
print(sum(nums))        # 57
print(nums.count(9))    # 3
nums.sort()             # 原地升序
print(nums)
nums.sort(reverse=True) # 原地降序
print(nums)
▶ Run
💡 关键点：sort()/reverse() 原地修改，返回 None；不会返回新列表。
概念 · 05

+ * in

拼接、重复、成员判断。

💡比喻：+ 拼在一起、* 复制几份、in 问『在不在』。
示例代码 · 点 ▶ Run 试运行
demo.py
a = [1, 2, 3]
b = [4, 5, 6]
print(a + b)     # [1,2,3,4,5,6]（新列表）
print(a * 2)     # [1,2,3,1,2,3]
print(2 in a)    # True
print(9 in a)    # False
▶ Run
💡 关键点：+ 和 * 生成新列表、不改原列表；in 常配合 if 使用。
