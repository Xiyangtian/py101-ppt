分支结构 if / elif / else

让程序会『思考』——条件判断与嵌套

概念 · 01

if —— 岔路口

条件为真走 if 块，否则依次判断 elif，最后走 else。

💡比喻：if 是岔路口，看条件决定走哪条路。
示例代码 · 点 ▶ Run 试运行
demo.py
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("再加油")
▶ Run
💡 关键点：条件后必须有冒号 :，代码块必须缩进（4 空格或 1 Tab）。
概念 · 02

多条件 & 嵌套

用 and/or 组合，或用嵌套 if。

💡比喻：条件往往是『比较』或『逻辑』的结果；路口里还能有小路口。
示例代码 · 点 ▶ Run 试运行
demo.py
age = 15
gender = "男"
if gender == "男" and age < 18:
    print("男孩")
elif gender == "男" and age >= 18:
    print("男人")
elif gender == "女" and age < 18:
    print("女孩")
else:
    print("女人")
▶ Run
💡 关键点：多条件用 and/or 连接，或拆成嵌套分支，两种写法都对。
概念 · 03

实例：出租车计费

分段计价：一段一个价。

💡比喻：从小到大分段判断，先判断近距离，别漏判。
示例代码 · 点 ▶ Run 试运行
demo.py
km = int(input("请输入距离(km): "))
if km <= 3:
    cost = 10
elif km <= 16:
    cost = 10 + (km - 3) * 2.7
else:
    cost = 10 + (16 - 3) * 2.7 + (km - 16) * 3
print(cost)
▶ Run
💡 关键点：验证：2→10；12→34.3；25→72.1。多分支要按顺序写，否则漏判。
