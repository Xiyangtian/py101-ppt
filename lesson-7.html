字符串与列表的操作

共有操作、split/join、字符串与列表互转

概念 · 01

共有操作

字符串和列表很多操作是一样的。

💡比喻：都一样能：+ 拼、* 复制、切片、用 in 问在不在。
示例代码 · 点 ▶ Run 试运行
demo.py
s = "帅气的方块鸟"
lst = [1, 2, 3]
print(s + "老师们")   # 字符串拼接
print(lst + [4, 5])   # 列表拼接
print("红" * 3)         # 红红红
print(2 in lst)        # True
print("块" in s)       # True
▶ Run
💡 关键点：拼接/重复生成新对象，原数组不变；in 做成员判断。
概念 · 02

字符串属性

字符串不可变，但有很多方法。

💡比喻：字符串是『不能改』的，只能靠方法或切片得到新字符串。
示例代码 · 点 ▶ Run 试运行
demo.py
s = "a,b,c"
print(s.split(","))       # ["a","b","c"]（拆成列表）
print("-".join(["a","b"]))  # "a-b"（拼回字符串）
print("  abc  ".strip())     # "abc"（去空格）
print("方块鸟"[::-1])        # 鸟块方（翻转用切片）
# "方块鸟"[0]="x"  # 报错！字符串不可改
▶ Run
💡 关键点：split() 字符串→列表；join() 列表→字符串，方向相反要记牢。
概念 · 03

列表属性

列表可变，方法就地修改。

💡比喻：列表是『可变』的，能直接改、能就地排序反转。
示例代码 · 点 ▶ Run 试运行
demo.py
lst = [1, 2, 3, 4, 5]
lst.reverse()    # 就地反转
print(lst)       # [5,4,3,2,1]
lst.append(6)
lst.insert(0, 0)
lst.remove(5)    # 删第一个出现的 5
print(lst)
▶ Run
💡 关键点：remove(x) 删第一个匹配值；列表没有值会报错。
概念 · 04

字符串 ↔ 列表

处理文本和数据组时经常互转。

💡比喻：split 把一句话拆成一份份；join 把一份份拼回一句话。
示例代码 · 点 ▶ Run 试运行
demo.py
s = "1-2,3-4,5-6"
print(list(s))          # 逐字符拆
print(s.split(","))     # ["1-2","3-4","5-6"]
print(s.split("-"))     # ["1","2,3","4,5","6"]

lst = ["我有", "1只", "小毛驴"]
print("".join(lst))     # 我有1只小毛驴
print("_".join(lst))    # 我有_1只_小毛驴
▶ Run
💡 关键点：列表里若有数字，join 前要先 map(str, 列表) 转字符串。
概念 · 05

处理数字字符串

拆、转、排序、拼。

💡比喻：先 split 拆开，再 map(int) 变数字，sort 排序，join 拼回去。
示例代码 · 点 ▶ Run 试运行
demo.py
s = "2*4*5*1*27*3*9"
nums = s.split("*")
nums = list(map(int, nums))
print(max(nums), min(nums))   # 27 1
nums.sort()
print("-".join(map(str, nums)))  # 1-2-3-4-5-9-27
▶ Run
💡 关键点：map(int, 列表) 转整数，map(str, 列表) 转字符串。
