概念 · 01

变量 —— 电脑的碗

变量像一个贴了标签的碗，用来存数据，通过名字访问。

💡比喻：碗是一样的碗，贴的标签（变量名）不一样，装的东西也不一样。
示例代码 · 点 ▶ Run 试运行
demo.py
name = "小明"     # 字符串
grade = 13        # 整数
tall = 1.55       # 浮点数
print("我叫", name, "今年", grade, "岁")
▶ Run
💡 关键点：= 是赋值，把右边数据存进左边变量。变量要先赋值再用。
概念 · 02

变量命名规则

字母、数字、下划线；数字不能开头；不能用保留字。

💡比喻：名字要像路牌：别人看得懂、不撞名、不打头阵用数字。
示例代码 · 点 ▶ Run 试运行
demo.py
# 合法：
my_name = "Tom"
_score2 = 90

# 非法：
# 1name = 5   数字开头 ❌
# if = 5      保留字 ❌
# my-name = 5 含短横线 ❌
▶ Run
💡 关键点：不能用保留字（if、while、True、False等）做变量名；区分大小写。
概念 · 03

注释 —— 给代码写说明

注释不会被执行，只给人看。

💡比喻：# 是单行便签；三个引号是整段便签。
示例代码 · 点 ▶ Run 试运行
demo.py
# 这是单行注释（用 # 开头）
print("你好")   # 行尾也可以

"""
这是多行注释
用三个双引号或单引号包围
"""
▶ Run
💡 关键点：考试常考：单行注释用 #，多行用三引号。双引号是字符串，不是注释。
概念 · 04

四大基本数据类型

字符串、整数、浮点数、布尔。

💡比喻：文字要引号、数字分两种（带不带小数点）、真假是开关、空心是 None。
示例代码 · 点 ▶ Run 试运行
demo.py
s = "Hello"      # 字符串 str
n = 42           # 整数 int
f = 3.14         # 浮点数 float
b = True         # 布尔 bool（True/False）
none = None      # 无值
▶ Run
💡 关键点：字符串可 + 拼接、\n 换行；用 type(x) 查看类型。
概念 · 05

类型转换 —— 翻译官

在字符串、整数、浮点数、布尔之间互相转换。

💡比喻：str/int/float/bool 是四个翻译官，把一种类型翻译成另一种。
示例代码 · 点 ▶ Run 试运行
demo.py
age = 14
print("你今年" + str(age) + "岁")

a = int("123")       # 字符串→整数
b = float(4)         # 整数→浮点数 4.0
print(int(3.6))      # 3（截断，不是四舍五入）
print(bool(0))       # False
print(bool(" "))     # True（含空格的字符串为真）
▶ Run
💡 关键点：int("3.5") 会报错，需先 float() 再 int()；float→int 是截断。
