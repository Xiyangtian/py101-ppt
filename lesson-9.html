概念 · 01

try-except —— 护身符

可能出错的地方用 try 包起来，出错走 except。

💡比喻：把可能出错的地方『护起来』，出错也不让程序崩溃。
示例代码 · 点 ▶ Run 试运行
demo.py
try:
    a = float(input("请输入数值: "))
    print("你输入的是", a)
except:
    print("输入有误，请重新输入")
▶ Run
💡 关键点：输入『好的』时 float() 会报错，被 except 捕获，提示重输而不是崩溃。
概念 · 02

循环到输入正确

while True + try-except，直到输入合法。

💡比喻：直到学生做对为止——不停问，问对了才放行。
示例代码 · 点 ▶ Run 试运行
demo.py
while True:
    try:
        x = int(input("请输入一个整数: "))
        print(x)
        break
    except:
        print("输入的不是整数，请重试")
▶ Run
💡 关键点：输入非法就 except，循环继续；输入合法就 break 结束。
概念 · 03

eval —— 当算式算

把字符串当作表达式执行并返回结果。

💡比喻：eval 把字符串『当算式』算出来，一行顶一堆代码。
示例代码 · 点 ▶ Run 试运行
demo.py
print(eval("2 + 3"))      # 5
print(eval("3 * 4"))       # 12
expr = input("输入算式: ")
print("结果:", eval(expr))
▶ Run
💡 关键点：考试中了解它会计算字符串表达式即可。
概念 · 04

真题编程题

读题→拆解→写码→跑通。

💡比喻：操作题拿分关键是『能跑通』，先看清输入/输出格式再动手。
示例代码 · 点 ▶ Run 试运行
demo.py
# ① 两数之差与和
a = int(input()); b = int(input())
print(abs(a - b)); print(a + b)

# ② 评委平均分
s = input(); nums = list(map(int, s.split()))
print(round(sum(nums)/len(nums)))

# ③ 最小公倍数
a,b = int(input()), int(input())
gcd = max(i for i in range(1, min(a,b)+1) if a%i==0 and b%i==0)
print(a*b//gcd)
▶ Run
💡 关键点：① abs 差值；② split+map+round；③ 两数之积 ÷ 最大公约数。
