运算符与表达式

算术、比较、逻辑运算符与优先级

概念 · 01

算术运算符

做数学运算，返回数值。

💡比喻：数学课老朋友，新认识 // （整除）和 % （取余）。
示例代码 · 点 ▶ Run 试运行
demo.py
print(5 + 3)     # 8
print(5 / 3)     # 1.6666...（除法是浮点数）
print(5 % 3)     # 2（取余）
print(5 ** 3)    # 125（幂）
print(7 // 2)    # 3（整除向下）
▶ Run
💡 关键点：% 常用来判断奇偶/整除；/ 结果一定是浮点数。
概念 · 02

比较运算符

比较两值，返回布尔 True/False。

💡比喻：只回答『是/否』的问题：是否相等、谁大谁小。
示例代码 · 点 ▶ Run 试运行
demo.py
print(5 == 3)   # False（等于）
print(5 != 3)   # True（不等于）
print(5 > 3)    # True
print(5 >= 5)   # True
print(3 <= 1)   # False
▶ Run
💡 关键点：= 赋值，== 比较。3 == "3" 结果是 False（类型不同）。
概念 · 03

逻辑运算符

组合多个条件，常用于 if。

💡比喻：and 要都对、or 有一个对就对、not 反过来。
示例代码 · 点 ▶ Run 试运行
demo.py
print(not True)          # False
print(True and False)   # False
print(True or False)    # True

# 短路：and 左假不再算右边；or 左真不再算右边
print(False and (1/0))  # 不报错，右边没执行
▶ Run
💡 关键点：短路特性常考：False and 后面写什么都没关系，不会执行。
概念 · 04

优先级

从高到低：括号 > 幂 > 乘除 > 加减 > 比较 > 逻辑。

💡比喻：拿不准就加括号，最保险也最好读。
示例代码 · 点 ▶ Run 试运行
demo.py
print(2 + 3 * 4)      # 14：先乘后加
print((2 + 3) * 4)    # 20：括号优先
print(2 ** 3 ** 2)    # 512：幂是右结合
print(8 - 3 + 2)      # 7：左结合
▶ Run
💡 关键点：算术左结合、幂右结合；把不确定的用括号包起来。
